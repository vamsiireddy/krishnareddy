CI/CD Demo Application Developed by Vamsi Krishna Reddy

About This Project

This project demonstrates a complete CI/CD pipeline where code changes pushed to GitHub automatically trigger Jenkins, build the project using Maven, and deploy it to Apache Tomcat.

Git Push → Jenkins Build → Maven Package → Tomcat Deploy

Technologies Used

  • Git & GitHub – Source Code Management
  • Jenkins – Continuous Integration
  • Apache Maven – Build Automation
  • Apache Tomcat – Application Deployment
  • Java 17 – Application Runtime
  • AWS EC2 – Hosting Environment

CI/CD Objective

The goal of this project is to automate the build and deployment process, reduce manual intervention, and ensure faster and reliable application delivery.
